Connected Accounts

Humble Bundle

  1. Log in at humblebundle.com in this browser, if you aren't already.
  2. Open developer tools (press F12, or right-click the page → Inspect), then find Application (Chrome/Edge) or Storage (Firefox) → Cookies → https://www.humblebundle.com in the panel that opens.
  3. Find the cookie named _simpleauth_sess in that list and copy its Value.
  4. Paste it below and click Save.

There's no username/password login here — Humble's own login is behind Cloudflare's bot protection, which blocks non-browser login attempts outright, so this manual cookie handoff (the same one humble-cli itself uses) is the only way in. It doesn't expire on a fixed schedule, but Humble may invalidate it eventually; if actions start failing, come back here and paste a fresh one.

{% include "settings/_humble_form.html" %}

Steam

Compares your bundles' Steam keys against your actual Steam library, so you can see which ones you've never redeemed.

  1. Get a free API key at steamcommunity.com/dev/apikey — any domain name works for personal use, e.g. localhost.
  2. Enter that key below, plus either your SteamID64 or your profile URL/vanity name (e.g. steamcommunity.com/id/yourname) — whichever you already have works, no need to look up the numeric ID separately.
  3. Make sure your profile and game details are set to Public in your Steam privacy settings, or the owned-games list won't be readable.
{% include "settings/_steam_form.html" %}

GOG

Compares your bundles' GOG keys against your actual GOG library. Click Connect below and follow the 3 steps in the popup — GOG has no public API key like Steam's, so this is a one-time manual log-in-and-paste-the-URL-back step instead. The code GOG gives you expires within a minute or two, so it may take a try or two to get through in time.

Note: very few Humble bundles actually expose a matchable GOG key today (confirmed against this library: 2 GOG-type keys total, neither matchable), so don't expect much from the "never redeemed" comparison yet — the games catalog itself still works regardless.

Audible

Lists your owned Audible audiobooks. Amazon has no public Audible API, and Amazon now blocks a plain automated login outright — so connecting means a one-time manual step, similar to GOG above: click a link to log in on Amazon's own site in a real browser, then copy the resulting URL back here. Nothing is stored in plaintext: the resulting login is encrypted at rest the same way every other connected account here is.
